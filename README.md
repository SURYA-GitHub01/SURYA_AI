# SURYA_AI

## OpenAI API Key Setup

### 1. Edit your shell configuration
```bash
nano ~/.zshrc   # or nano ~/.bashrc


# Set OpenAI API key
export OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx

# Reload shell to apply changes
source ~/.zshrc   # or source ~/.bashrc

# Verify the key
echo $OPENAI_API_KEY
```
